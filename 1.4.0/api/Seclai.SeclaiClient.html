    Remarks

    Opt-in. The methods on the client itself keep returning JsonElement so existing call sites are unaffected; the same endpoints are available here deserialized into models. Both issue exactly the same request — only the return type differs.

var typed = await client.Typed.SearchAsync("q");  // SearchResponse
