    Class SetSlackTriggerConfigRequest

    Slack connection, form, channels, visibility and conversation settings for an agent's SLACK_COMMAND trigger, which people run from Slack with /seclai or the message shortcut.

    public sealed class SetSlackTriggerConfigRequest
    Remarks

    A property left null is omitted from the request and the server leaves that setting unchanged. The server refuses a request that leaves the trigger without a Slack (Bot) connection.
