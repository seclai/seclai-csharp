    Remarks

    A struct rather than a class so that a bare null argument cannot convert to it and binds to the method's original overload. A default value polls exactly as the original overload does with its defaults.

    Timeout

    Maximum time to wait for an unfinished run; null waits until the run ends. The request that starts the run is not bounded by it, since the server may already have created the run: as in 1.7.0, the HttpClient's timeout (Timeout when the SDK creates the client) and the caller's token bound it. Nor is the fetch of step outputs for a start response that already ends the poll. When it elapses before the run finished, OperationCanceledException is thrown, or, with ThrowOnIncomplete, StreamingException.
