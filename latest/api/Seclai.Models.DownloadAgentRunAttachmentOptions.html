    Remarks

    A default value downloads exactly as DownloadAgentRunAttachmentAsync(string, string, string?, CancellationToken) does with no downloadName: the whole file, adding no Range header.

    The range fields build one Range header. Set none of them, RangeStart alone (bytes=start-), RangeStart and RangeEnd (bytes=start-end), or RangeSuffix alone (bytes=-suffix). Any other combination throws ArgumentException before a request is sent.
